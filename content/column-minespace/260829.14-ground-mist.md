# Minespace - EP14：貼地晨霧

大家好，我是鱈魚。

上一章在空氣裡撒了一把顆粒。這一章要在同一片空氣裡再鋪一層東西，只是這次它貼在地上，而且只在一天當中很短的一段時間出現。%( ˘•ω•˘ )%

## 晨霧是什麼時候出現的

霧會積在地面，是因為夜裡地表放熱降溫，貼著地面那一層空氣先冷下來，水氣就凝在那裡。

所以晨霧的時間點很固定。天還沒亮的時候它已經積在那裡，太陽一升起就開始曬散。

專案裡的一天是零到一的循環，破曉在 0.18、日出在 0.24。晨霧的四個節點照著這兩個數字抓。

```ts
const MIST_RISE_FROM = 0.09
const MIST_RISE_TO = 0.18
const MIST_FADE_FROM = 0.27
const MIST_FADE_TO = 0.41
```

淡入九分之一天、淡出十四分之一天，出來的時間比散掉的時間短。太陽把霧曬散的那一段是晨霧最好看的地方，值得拖久一點。

### 濃度曲線

```ts
export function getDawnMistRatio(timeOfDay: number): number {
  if (timeOfDay <= MIST_RISE_FROM || timeOfDay >= MIST_FADE_TO)
    return 0

  if (timeOfDay < MIST_RISE_TO)
    return smoothRange(timeOfDay, MIST_RISE_FROM, MIST_RISE_TO)

  if (timeOfDay > MIST_FADE_FROM)
    return 1 - smoothRange(timeOfDay, MIST_FADE_FROM, MIST_FADE_TO)

  return 1
}
```

四個節點把一天切成五段，中間那段給滿，兩側各走一條 smoothstep。

```ts
function smoothRange(value: number, from: number, to: number): number {
  const ratio = Math.min(1, Math.max(0, (value - from) / (to - from)))

  return ratio * ratio * (3 - 2 * ratio)
}
```

`t²(3 - 2t)` 這條曲線在兩端的斜率都是零，所以霧開始出現與完全散掉的那一刻不會有轉折。直線的話，那兩個時間點上會看到濃度突然開始變化。

算出來的比例直接乘在發射率上。

```ts
const fullEmitRate = maxParticleCount / 14

particleSystem.emitRate = fullEmitRate * getDawnMistRatio(timeOfDay)
```

滿檔的發射率照容量除以平均壽命算。同時活著的數量大約是「發射率乘上平均壽命」，除以十四剛好把容量填滿而不撞到上限。

## 第二步：霧片要貼著地面長出來

粒子系統預設用 `minEmitBox` 與 `maxEmitBox` 夾出一個長方體，顆粒隨機生在裡面。

這對貼地的霧不夠用。庭園是一座座抬高的木座加上木座之間的白沙，高低差有好幾格，一個固定的高度只會得到一片橫穿所有東西的白板。

霧要積在低處、繞著木座的邊緣走，就得先知道每一個位置的地面有多高。

### 用射線問世界

```ts
particleSystem.startPositionFunction = (_worldMatrix, positionToUpdate) => {
  const radius = Math.random() ** 0.7 * MIST_RADIUS
  const angle = Math.random() * Math.PI * 2
  const x = emitter.x + Math.cos(angle) * radius
  const z = emitter.z + Math.sin(angle) * radius
  const surfaceY = castRainRay(Math.floor(x + 0.5), Math.floor(z + 0.5)) ?? 0

  positionToUpdate.set(
    x,
    surfaceY + MIST_MIN_HEIGHT + Math.random() * (MIST_MAX_HEIGHT - MIST_MIN_HEIGHT),
    z,
  )
}
```

`startPositionFunction` 一給，那兩個發射盒就不算數了，每一片霧生在哪裡完全由這個函式決定。

`castRainRay` 是從天空往下打的一道射線，回傳它撞到的第一個實心頂面。這道射線本來是給雨滴用的，晨霧、沼澤霧與落葉後來都接到同一支。

```ts
export function castRainRay(state: Uint8Array, x: number, z: number): number | null {
  for (let y = WORLD_HEIGHT - 1; y >= 0; y--) {
    const blockId = getBlock(state, x, y, z)
    if (blockId === BlockId.AIR)
      continue
    if (isPassableBlock(blockId) && !isWaterBlock(blockId))
      continue

    return y - 0.5 + getCollisionHeight(blockId)
  }

  return null
}
```

方塊世界的好處在這裡看得很清楚。射線不必真的做幾何相交，從天空那一格往下數，遇到第一個擋得住的就停。花草這類穿得過去的方塊直接跳過，半磚只有半格高，水面則擋在水的頂面。

### 半徑的取樣要偏向中心

```ts
const radius = Math.random() ** 0.7 * MIST_RADIUS
```

`Math.random()` 均勻散在零到一之間，直接乘上半徑的話，外圈那一圈會比內圈稀薄很多。圓的面積跟半徑平方走，同樣的角度區間在外圈涵蓋的面積大得多。

開零點七次方把取樣往中心壓一點。腳邊的霧最密，越往外越疏，邊緣自然就散開了。%(๑´ㅂ`๑)%

### 高度給到過腰而不過肩

```ts
const MIST_MIN_HEIGHT = 0.1
const MIST_MAX_HEIGHT = 1.9
```

上界壓在一格九，也就是人的胸口。晨霧的辨識度全在「它比人矮」這件事上，一旦漫過頭頂，畫面上就只剩一片白，看起來像走進雲裡。

關掉貼地之後那片白板非常明顯，木座整個泡在裡面，霧與地形完全沒有關係。%(⊙ o ⊙)%

## 第三步：遠景交給高度霧

粒子只鋪在身邊三十幾格。再遠的地方，一片霧在畫面上只剩幾個像素，撒再多也堆不出厚度，卻照樣要進每一幀的更新與排序。

遠處那一層要用另一種做法。

場景內建的霧只看距離，不管在什麼高度，一律照離鏡頭多遠往霧色收。真實的空氣是有重量的，濁的那一層積在低處，這是為什麼從山上往下看，山谷總是比山脊模糊。

所以在霧的濃度上再乘一個看高度的倍率。

```glsl
float fogAmount = clamp(1.0 - fog, 0.0, 1.0);
float lowRatio = clamp((groundHaze.x - vPositionW.y) * groundHaze.y, 0.0, 1.0);
fogAmount = clamp(fogAmount * (1.0 + lowRatio * groundHaze.z), 0.0, 1.0);
color.rgb = mix(color.rgb, vFogColor, fogAmount);
```

`groundHaze` 那三個分量分別是濁氣的頂、往下加厚的速度，以及貼著地面時要濃多少。

```ts
const GROUND_HAZE_TOP = SAND_LEVEL + 10
const GROUND_HAZE_FALLOFF = 1 / 12
const GROUND_HAZE_BOOST_BASE = 0.6
```

頂抓在沙面上十格，木座、鳥居與矮松都泡在裡面，樹冠與山頭則露在上面。清晨從高處往下看時，整片庭園浮在一層薄濁上，就是這個高度切出來的。

加厚的速度給十二格的倒數。從樹冠到地面是一段連續的漸變，不會出現一條水平的界線。

第三個是**倍率**。近處的東西完全不受影響，乘上零還是零，只有本來就有點遠的東西會再糊一點。直接相加的話，腳邊的方塊會憑空罩上一層灰。

這一段程式碼要換進 `StandardMaterial` 的片段著色器裡，走的是材質外掛。那套機制在 EP05 講雲影時已經完整介紹過，這裡只用到它的兩件事，登記幾個 uniform 與換掉霧的那一行。

<demo-mist-heightfog />

把加厚拉到零就退回原本的單色霧，柱子從底到頂糊得一樣多。拉起來之後，同一根柱子的下半截先沉進霧裡，頂端還留在外面。

## 第四步：濃度隨太陽仰角變化

貼地水氣最看得出來的時候，是太陽貼著地平線那一段。逆光穿過一層薄霧，是晨昏辨識度最高的畫面之一。

所以那個倍率不是固定的，它跟著太陽的仰角走。

```ts
const GROUND_HAZE_BOOST_DAWN_DUSK = 1.15
const GROUND_HAZE_LOW_SUN_HEIGHT = 0.12
const GROUND_HAZE_HIGH_SUN_HEIGHT = 0.55

function computeGroundHazeBoost(sunHeight: number): number {
  const ratio = (sunHeight - GROUND_HAZE_LOW_SUN_HEIGHT)
    / (GROUND_HAZE_HIGH_SUN_HEIGHT - GROUND_HAZE_LOW_SUN_HEIGHT)
  const clamped = Math.min(1, Math.max(0, ratio))
  const smooth = clamped * clamped * (3 - 2 * clamped)

  return GROUND_HAZE_BOOST_DAWN_DUSK
    + (GROUND_HAZE_BOOST_BASE - GROUND_HAZE_BOOST_DAWN_DUSK) * smooth
}
```

仰角低的時候給到 1.15，正午收回基準的 0.6，中間一樣用平滑曲線接起來。太陽爬升的過程因此看不出任何一道分界。

太陽仰角直接拿平行光的方向來算。

```ts
updateAerialAir(fogColor, skyMidColor, clearRatio, -sunLight.direction.y)
```

光往下照的時候 `direction.y` 是負的，取負號就成了「太陽在天上多高」。零是貼著地平線、一是正上方。

這個量法整個專案共用，雲影判斷太陽高度用的也是同一個數字。

## 第五步：兩層的分工

現在手上有兩套東西，該怎麼分配。

**粒子給近景。**它是一片一片真的存在於世界上的東西，會被木座擋住、會繞著邊緣走、會隨著人前進而慢慢補上。近處那種「霧是有厚度的」感覺只有它做得出來。

**高度霧給遠景。**它是一行公式，成本與距離無關，而且天涯海角都有效。遠處那一整片的層次交給它。

兩者的接手點靠半徑決定。

```ts
const MIST_RADIUS = 34
```

粒子的半徑抓得比場景霧開始作用的距離再遠一點。走在裡面時前方那一片是連續的，再遠的地方交給場景霧接手，兩者之間沒有一條看得出來的界線。

<demo-mist-layers />

只留粒子的時候，遠處是一片平的白，沒有層次；只留高度霧的時候，腳邊乾乾淨淨，霧從幾十格外才開始。兩層疊起來才是從腳邊一路連到天邊的一片霧。%ヽ(●`∀´●)ﾉ%

### 發射點同樣跟著鏡頭走

```ts
const RECENTER_INTERVAL = 0.4

recenterElapsed += deltaTime
if (recenterElapsed < RECENTER_INTERVAL)
  return

recenterElapsed = 0
emitter.copyFrom(camera.position)
```

與上一章的浮塵是同一招。已經生出來的霧片留在原地，只有新的那些照著現在的位置撒，於是走過的路上霧會慢慢散掉，前方則慢慢補上。

間隔比浮塵的四分之一秒再放寬到零點四秒。霧片的半徑有三十四格，位置差個一兩格完全看不出來。

## 完整實作

`ground-mist.ts` 整支就是這幾件事。

1. 依時刻算出這一刻該有多濃
2. `startPositionFunction` 打一道射線，把霧片貼著地表生出來
3. 發射點每零點四秒對齊一次鏡頭
4. 高度霧那一層由大氣透視的外掛順手做掉

呼叫端還要再乘幾個條件。

```ts
const dawnRatio = getDawnMistRatio(getTimeOfDay())

groundMist.update(
  camera,
  dawnRatio * (1 - caveRatio) * (1 - rainRatio) * (1 - swampMistRatio) * edgeHideRatio,
)
```

洞裡沒有晨霧，那裡照不到太陽；下雨時也沒有，天已經是一片鉛灰；沼澤上更不必，那裡本來就有一片更濃的。

這幾個條件全部寫成零到一的比例再相乘，好處是走進洞口、雨勢轉大、踏進沼澤這幾件事都是連續的，沒有任何一個瞬間會看到霧整批消失。%( •̀ ω •́ )✧%
