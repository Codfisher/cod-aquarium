# Minespace - EP11：水面倒影

大家好，我是鱈魚。

前兩章都在處理水面以下，白沫、光網、水有多淺。這一章換到水面以上。

一方靜水最有說服力的東西是倒影。岸邊的石燈籠、頭上的雲、黃昏的天色，全部在水裡再來一次，而且是上下顛倒的。%( •̀ ω •́ )✧%

## 鏡子的原理

倒影的做法比想像中直白，把整個場景以水面為鏡面再畫一次，畫到一張圖上，然後把那張圖貼回水面。

鱈魚：「所以是把每個東西複製一份，翻過來擺在水底下？」
路人：「那你有幾百顆方塊要複製？」
鱈魚：「…好啦，翻的是鏡頭，東西一顆都不動。」

真正翻過去的是視點。把鏡頭對著水面鏡射一次，從那個位置再畫一趟，畫出來的就是水裡該看到的樣子。

Babylon 把這件事包成 `MirrorTexture`，用起來像一張普通的算繪目標。

```ts
const texture = new MirrorTexture('water-mirror', 512, scene, true)
texture.mirrorPlane = new Plane(0, -1, 0, surfaceY)
texture.renderList = renderList
```

三行，一行一件事。第一行決定圖多大，第二行決定鏡面在哪，第三行決定要映什麼。

## 第一步：鏡面方程式

平面在 Babylon 裡是四個數字，前三個是法線、第四個是位移，滿足 `法線 · 位置 + 位移 = 0` 的點就在平面上。

水面是一片水平的面，位置在 `y = surfaceY`。代進去。

```ts
new Plane(0, -1, 0, surfaceY)
```

法線給朝下的 `(0, -1, 0)`，方程式展開是 `-y + surfaceY = 0`，也就是 `y = surfaceY`。%( ˘•ω•˘ )%

<demo-mirror-plane />

法線翻成朝上會怎樣，範例裡試一次就知道。整個倒影會映到水面上方去，鳥居倒插在天上。

位移這個數字也不能隨便給。水是液體，最上層那一格會矮掉八分之一格；冰是實心方塊，頂面就是格子的頂面。差的那一點點會讓倒影浮在冰面上方或沉進冰裡。

```ts
surfaceY: topLayerY + 0.5 - (surface === 'water' ? LIQUID_SURFACE_DROP : 0)
```

## 第二步：反射清單

`renderList` 決定鏡子裡有什麼。沒進清單的東西在水裡不存在。

<demo-mirror-renderlist />

只映天空的話，池面上看得到雲飄過去，岸邊那圈石燈籠卻不在水裡。那看起來就像一塊開在地上的天窗。%(´థ‸థ)%

所以兩邊都要進來。

```ts
const skyMeshList = [
  SKYBOX_NAME,
  STAR_FIELD_NAME,
  SUN_DISC_NAME,
  SUN_GLOW_NAME,
  MOON_DISC_NAME,
  MOON_GLOW_NAME,
  CLOUD_LAYER_NAME,
  OVERCAST_NAME,
]
  .map((name) => scene.getMeshByName(name))
  .filter((mesh) => !!mesh)

const blockMeshList = scene.meshes.filter((mesh) => mesh.name.startsWith(BLOCK_MESH_PREFIX))

texture.renderList = [...skyMeshList, ...blockMeshList]
```

天空那一組要逐個指名，因為天空是好幾個網格湊出來的。太陽、月亮、它們各自的光暈、星空、雲層、陰天那一片罩子，少一個就是水裡少一樣東西。

地景這邊撈的是方塊網格。這個世界是逐方塊類型一個網格配 thin instance 畫的（見 EP02），所以加進來的成本是「每種方塊多一次繪製呼叫」，每一顆方塊並不會各記一筆。

路人：「那植物、粒子、光暈那些呢？」
鱈魚：「都沒進去。倒影是要付錢的，貴的東西先不放。」

## 第三步：材質只留倒影

倒影面是一片獨立的網格，貼著水面浮在上頭。它的材質只有一個任務，所以其他通道全部關掉。

```ts
const material = new StandardMaterial('water-mirror-material', scene)

material.diffuseColor = new Color3(0, 0, 0)
material.specularColor = new Color3(0, 0, 0)
material.emissiveColor = new Color3(0, 0, 0)
material.disableLighting = true
material.reflectionTexture = texture
material.reflectionTexture.level = 1
```

反射在 `StandardMaterial` 裡是加在最後的一項。漫射與自發光留著的話，會在倒影上疊一層灰。

濃度用 `alpha` 給。

```ts
material.alpha = 0.5
material.transparencyMode = Material.MATERIAL_ALPHABLEND
```

倒影疊在水上，水自己的顏色與流動都還要看得見。給到滿就成了一面真的鏡子，那時水的存在感反而不見了。

還有一項要記得關。

```ts
material.fogEnabled = false
```

倒影裡的東西已經是從場景取來的顏色，各自吃過自己那一份霧了。這裡再套一次會讓水面比它映的東西更灰。

### 抬高兩公分

倒影面與水面幾乎同高，而兩片幾乎同高的半透明面會互相爭深度，畫面上是一片閃爍的雜訊。

```ts
const SURFACE_LIFT = 0.02

mesh.position.set(centerX, surfaceY + SURFACE_LIFT, centerZ)
```

抬高兩公分，深度就分得開了，而兩公分在畫面上量不出來。%(´,,•ω•,,)%

## 第四步：邊緣要淡出

倒影面是一片方形的板子，而水池不是方的。

沒有處理的話，水池的四個角會露出筆直的邊，看起來像鋪了一塊玻璃。做法是給材質一張透明度貼圖，中心是滿的、往外收到全透明。

```ts
const gradient = context.createRadialGradient(size / 2, size / 2, 0, size / 2, size / 2, size / 2)
gradient.addColorStop(0, 'rgba(255, 255, 255, 1)')
gradient.addColorStop(0.62, 'rgba(255, 255, 255, 1)')
gradient.addColorStop(1, 'rgba(255, 255, 255, 0)')
```

內圈六成二維持全滿，最後那三成八化開。%( ´ ▽ ` )ﾉ%

<demo-mirror-fade />

倒影面本身也要比水真正的範圍再收窄一點。岸線是吃噪音生成的，凹凸不定，量出來的半徑是最外那一格的距離，照著鋪會讓倒影漫到岸上的草地。收掉三分之一格再讓邊緣淡出剛好。

### 解析度可以放心砍

範例裡那條解析度的滑桿一路往下拉，其實掉得很慢。

倒影本來就不該比實景銳利。水面在晃、倒影在抖，那是水的本性，一方水池用二五六完全看不出差別。

但這個數字得跟著範圍走。蛙聲澤那片水量出來半徑將近二十格，同一張圖攤在四十格見方的面上只剩每格六個像素，倒影會糊成一片色塊。

```ts
const textureSize = surface.radius > LARGE_MIRROR_RADIUS ? mirrorSizeLarge : mirrorSizeSmall
```

兩個尺寸住在畫質設定表裡，每一級各有一組，最省的那一級給零就是整個不做。走到水邊掉幀的話，這是第一個該減半的數字。

## 第五步：什麼時候才畫

一面鏡子等於那一帶的地景多畫一趟。這是這個效果唯一的成本，也是全部的成本。

所以要省，而且要省得徹底。

### 只給特定水景

第一刀是一份刻意的名單。

```ts
const MIRROR_TARGET_LIST: MirrorTarget[] = [
  { garden: 'pond', surface: 'water' },
  { garden: 'swamp', surface: 'water' },
  { garden: 'cave', surface: 'water' },
  { garden: 'rainvale', surface: 'water' },
  /** 山腳下那窪凍住的融雪池 */
  { garden: 'alpine', surface: 'ice' },
]
```

世界上零星的水窪、湯屋的岩池、海岸那片淺灘都有水，但「有水就映」是付不起的。值得付錢的是那幾座「反光本身就是主題」的箱庭。

再加一道下限，一兩格的水缽給了鏡子也看不出來。

```ts
const MIN_WATER_COLUMN_COUNT = 9
```

### 走近才畫

第二刀更有效。

```ts
const ACTIVE_DISTANCE = 30
const CHECK_INTERVAL = 0.3
```

超過三十格就把整張圖從算繪清單裡拿掉。四座箱庭彼此相距數十格，所以同一刻至多只有一面鏡子在畫。

距離檢查每三分之一秒做一次就好，這件事不必每一幀算。

<demo-mirror-active />

關掉的方式有個地方容易漏。

```ts
function setActive(mirror: Mirror, nextActive: boolean): void {
  mirror.mesh.setEnabled(nextActive)
  mirror.texture.refreshRate = nextActive
    ? RenderTargetTexture.REFRESHRATE_RENDER_ONEVERYFRAME
    : 0
}
```

只把網格關掉是不夠的。算繪目標是掛在場景上的，網格看不看得見它都照畫，於是那一趟地景照樣走完，只是畫給沒人看的一張圖。頻率歸零才是真的不畫。%(・_・;)%

### 人在水面以下也關掉

最後補一個狀況。

```ts
const isAbove = camera.position.y > mirror.surfaceY
```

從水裡往上看不會看到倒影，那時該看到的是水面本身。而倒影面是單面的，從底下看過去只會是一片空白。

## 完整實作

倒影面要鋪多大，這件事最好從世界資料量出來。

專案裡原本是寫死的，四座箱庭的水各有各的高度與形狀，岩響窟的水在洞裡、聽雨亭的是一方淺池，照著抄四組座標，只要地形生成改一次就全錯，而且錯的樣子是「倒影浮在半空中」。

改成掃。逐格柱找最上層的水，照高度分組，取格數最多的那一層。

分組這一步是必要的。一座箱庭可能同時有主池與岸邊的小水窪，兩者高度不同，混在一起算出來的中心會落在兩池之間的岸上。

量範圍則用外接矩形。

```ts
const halfWidth = Math.max(1, (waterMaxX - waterMinX) / 2 + 0.5 - RADIUS_INSET)
const halfDepth = Math.max(1, (waterMaxZ - waterMinZ) / 2 + 0.5 - RADIUS_INSET)
```

另一種算法是「重心加上最遠一格的距離」，那會把面積灌水，而且水愈散愈嚴重。蛙聲澤的水鋪滿整座箱庭，重心落在正中央、最遠的是四個角，量出來的半徑是 14 × √2 ≈ 19.8，於是鋪出一面四十格見方的鏡子，而那座箱庭的木座只有三十二格寬。

多出來的那四格會從台座邊緣探出去，懸在外圈的石板路上方。%(›´ω`‹ )%

中心也要跟著改成矩形的中心。水池偏在箱庭一角時，重心與外接矩形的中心是兩個位置，用錯了鏡子會歪一邊。

## 總結 🐟

以上程式碼可以[在此取得](https://github.com/Codfisher/cod-aquarium/tree/main/content/aquarium/minespace)

- `MirrorTexture` 是把鏡頭對著水面鏡射一次，從那裡再畫一趟
- 鏡面方程式的法線朝下、位移等於水面高度
- 天空與地景都要進反射清單，少一邊就成了地上的天窗
- 倒影面抬高兩公分免得爭深度，邊緣用一張徑向遮罩淡出
- 成本是「那一帶的地景多畫一趟」，所以只給特定水景，而且走近才畫
