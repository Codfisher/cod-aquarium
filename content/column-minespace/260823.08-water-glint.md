# Minespace - EP08：水面高光

大家好，我是鱈魚。

一池不會動的水要怎麼看起來像水？

答案是太陽反在上面那一道光。人走一步，那個亮點就跟著移一步，比任何波紋貼圖都有效。%( •̀ ω •́ )✧%

這一章把那道光從頭做起來。

## 高光是怎麼算出來的

表面反射光分兩種。

一種是**漫射**（diffuse），光打進表面之後往四面八方彈出去，所以不管站在哪裡看，那塊地的顏色都一樣。磚牆、泥土、木頭都走這條路。

另一種是**高光**（specular），光幾乎照著入射角反出去，所以只有站在特定角度才看得到。鏡子、金屬、水面走的是這一條。

Babylon 的 `StandardMaterial` 用的是 Blinn-Phong 模型，式子很短。

```glsl
vec3 halfDirection = normalize(lightDirection + viewDirection);
float specular = pow(max(dot(normal, halfDirection), 0.0), glossiness);
```

`halfDirection` 是「往光源看」與「往眼睛看」這兩個方向的中間值。表面的法線剛好指在那個中間值上的時候，光就正好反進眼睛裡，那個點積等於一。

法線稍微歪一點，點積就掉下來。掉得多快由後面那個次方決定。

<figure-half-vector />

路人：「為什麼要繞一個中間值？直接算反射方向不行嗎？」
鱈魚：「行，那是原版的 Phong。半向量省掉一次反射計算，而且能量分布更接近真實的表面。」

## 第一步：specularColor 與 specularPower

材質上有兩個旋鈕。

**`specularColor`** 是這個表面有多亮，也就是反射率。它會乘在算好的高光上，決定那道光的強度與顏色。

**`specularPower`** 就是上面式子裡那個次方，決定高光收得多緊。

<demo-glint-blinn />

指數給到個位數，那道反光散成一整片，看起來像磨砂玻璃。給到一百六才收得緊，才是水面該有的一小點。%(⊙ o ⊙)%

專案裡水的配方是這樣。

```ts
material.specularColor = new Color3(0.8, 0.82, 0.85)
material.specularPower = 160
```

藍綠通道略高一點，反出來的那道光帶著一點水色。

## 第二步：光源端給滿，材質決定亮度

高光的最終亮度是兩個值相乘，光源的 `specular` 乘上材質的 `specularColor`。

這裡有個很容易踩到的配置。光源端給 0.1、材質端給 0.08，相乘之後只剩 0.008，整個場景實質上沒有高光這回事。%(´･_･`)%

乾方塊看不出差別，石頭本來就是霧面的。麻煩的是水面，材質那一端已經沒有空間可以往上調。

兩個旋鈕控制同一件事的時候，要留一個當作真正的旋鈕。所以光源這一端給滿。

```ts
sunLight.specular = new Color3(1, 1, 1)
```

「這個表面有多亮」交還給各自的材質。

```ts
/** 乾方塊，幾乎是霧面 */
material.specularColor = new Color3(0.02, 0.02, 0.02)
/** 淋濕的表面 */
material.specularColor = new Color3(0.42, 0.42, 0.42)
/** 水面 */
material.specularColor = new Color3(0.8, 0.82, 0.85)
```

<demo-glint-material />

光源這一端只有一個值，收掉它等於整個場景一起沒有高光。這個性質後面講天氣時會派上用場。

高光也會跟著光源強度縮放，所以夜裡換成月光的時候，池面只留下很淡的一道。

## 高光是唯一能突破亮度上限的通道

這一節是整章最要緊的地方。

看一下 Babylon 把顏色組起來的那幾行。

```glsl
vec3 finalDiffuse = clamp(diffuseBase * diffuseColor + emissiveColor + vAmbientColor, 0.0, 1.0) * baseColor.rgb;
vec3 finalSpecular = specularBase * specularColor;

vec4 color = vec4(finalDiffuse * baseAmbientColor + finalSpecular, alpha);
```

漫射與自發光在乘上貼圖**之前**就先夾在 1.0 了。光再強，那一項也只能亮到貼圖本身的顏色，之後就停在那裡。

高光則加在那道 clamp 外面。

<demo-glint-clamp />

左邊那顆亮到一個程度就不動了，右邊那顆一路亮下去。%(⊙ o ⊙)%

所以正午的池面真的會刺眼。整套渲染裡能做到這件事的只有高光這一條路，濕掉的木板與水面能不能反出一道真正的光，全靠它。

鱈魚：「那把漫射那一行的 clamp 拿掉不就好了！」
路人：「你要改人家引擎的著色器喔？%(´・ω・`)%」
鱈魚：「說得也是，而且拿掉之後陰影裡的地面也會一起爆掉。」

## 第三步：讓法線碎掉

現在的水面已經有一道很有說服力的反光了，但整池水從岸邊到湖心是同一個樣子。

水的法線統一改成朝上（材質配方裡的 `flatShaded`），整池水因此是一個光學上的平面。平面上只反得出一個點。

真正的水面是有起伏的，每一小塊的法線都朝著不同方向，於是太陽在上面碎成一整片會閃的亮片。

要重現這件事，該動的是法線。

<demo-glint-normal />

沒有畫上任何一個白點。那一整片閃爍是同一道陽光落在被推歪的法線上算出來的。%ヽ(●`∀´●)ﾉ%

做法是先定一個高度場，再從高度場取斜率。

```glsl
float waterHeight(vec2 point, float time) {
  return sin(point.x * 1.7 + time * 1.3) * 0.5
    + sin(point.y * 2.3 - time * 1.1) * 0.35
    + sin((point.x + point.y) * 3.1 + time * 1.9) * 0.22
    + sin((point.x - point.y * 1.4) * 4.7 - time * 2.3) * 0.14;
}
```

四道波的波長刻意不成整數倍，相位永遠對不齊，圖樣不會在幾秒後整片重複。速度也各自不同，長浪會慢慢追過短浪，疊出一段特別亮的再錯開。

斜率用差分取。

```glsl
float step = 0.08;
float center = waterHeight(point, time);
float slopeX = waterHeight(point + vec2(step, 0.0), time) - center;
float slopeZ = waterHeight(point + vec2(0.0, step), time) - center;

normalW = normalize(normalW + vec3(-slopeX, 0.0, -slopeZ) * strength);
```

高度往哪邊上升，法線就往哪邊的反面倒，所以兩個斜率都取負號。

<figure-normal-tilt />

注入點挑 `CUSTOM_FRAGMENT_BEFORE_LIGHTS`。這個位置 `normalW` 已經算好、還沒有人用過它，換掉之後漫射與高光吃到的都是新的那一根。

## 第四步：對齊到像素格

這套美術是十六格見方的像素畫，貼圖用最近鄰、法線用最近鄰、刻意不開 FXAA。

一片平滑起伏的水面疊上去，全場就只有它帶著平滑曲線，像在一幅點陣圖上蓋了一層向量圖形。

把取樣座標先對齊到貼圖的像素格再送進高度場就好。

```glsl
vec2 point = worldPosition.xz * scale;
point = floor(point * 16.0) / 16.0;
```

同一個貼圖像素裡的每一個片元共用同一根法線，於是那些亮片是一格一格的，與方塊表面上那些方方正正的像素同一個節奏。%( ˘•ω•˘ )%

範例裡那個「對齊像素格」的開關就是這一行的開關，關掉之後亮片會化成平滑的一團。

## 第五步：陰天要把高光單獨收掉

Babylon 只用 `intensity` 同時縮放漫射與高光，但這兩件事在天氣上的反應完全不同。

雲層把太陽打散之後，天空整片還是亮的，漫射只是變柔。高光需要一顆又小又亮的太陽，而雲最先抹掉的就是那一顆。

所以要分開收。

```ts
sunLight.intensity = atmosphere.lightIntensity * weatherRatio * (1 - caveRatio)

const specular = atmosphere.specularRatio * (1 - caveRatio)
sunLight.specular.set(specular, specular, specular)
```

<demo-glint-weather />

把「高光另外收」關掉之後，暴雨裡的水面照樣閃著一道刺眼的反光，而抬頭連太陽在哪都看不出來。%(›´ω`‹ )%

每種天氣各有一個 `specularRatio`。

```ts
CLEAR_ATMOSPHERE.specularRatio = 1
SWAMP_ATMOSPHERE.specularRatio = 0.45
RAIN_ATMOSPHERE.specularRatio = 0.05
SNOW_ATMOSPHERE.specularRatio = 0.04
```

這個值好用的地方在於它量的正是「天上有沒有一顆又小又亮的太陽」，所以雲影與葉片透光也拿它來當強度。三件事要的是同一個東西。%( •̀ ω •́ )✧%

## 完整實作

整章整理成一次。

1. 光源端的 `specular` 給滿，讓材質自己決定要反射多少
2. 水的材質給 `specularColor` 0.8、`specularPower` 160
3. 水面的法線統一朝上，整池水先變成一個光學上的平面
4. 材質外掛在光照之前把法線推歪，那道光自己碎成一片
5. 取樣座標對齊到十六分之一格，亮片跟著像素走
6. 天氣與洞穴用 `specularRatio` 把高光單獨收掉

最後補一件實作上的事。

水的最上層另外開了一份材質（理由留到下一章講），但那一份與水底下那些滿格的水必須是同一種水。高光的強度、透明度與混合方式差一點，岸邊就會看到一條界線。

所以這兩件事抽成同一個函式，兩份材質都走它。

```ts
class VoxelRenderer {
  private applyLiquidLook(material: StandardMaterial, blockDef: BlockDef): void {
    if (blockDef.isLiquid) {
      material.specularColor = new Color3(0.8, 0.82, 0.85)
      material.specularPower = 160
      this.liquidMaterialList.push(material)
    }

    if (blockDef.alpha !== undefined && blockDef.alpha < 1) {
      material.alpha = blockDef.alpha
      material.transparencyMode = Material.MATERIAL_ALPHABLEND
      material.backFaceCulling = true
      material.needDepthPrePass = true
    }
  }
}
```

## 總結 🐟

以上程式碼可以[在此取得](https://github.com/Codfisher/cod-aquarium/tree/main/content/aquarium/minespace)

- 高光走 Blinn-Phong，法線與半向量的點積再加一次次方
- `specularColor` 管有多亮，`specularPower` 管收得多緊，水面是 0.8 配 160
- 光源端給滿，材質那一端才有空間分辨乾方塊、濕木板與水面
- 漫射在乘上貼圖之前就夾在 1.0，高光加在那道 clamp 外面，正午的池面才真的會刺眼
- 讓法線隨波起伏，高光自己會碎成一片，畫面上不必灑任何白點
- 取樣座標對齊到像素格，亮片才與方塊表面同一個節奏
- 陰天要用 `specularRatio` 把高光單獨收掉，`intensity` 一起縮是不夠的
